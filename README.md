# 公司放假通知生成器

填写内容 → 自动生成日历 → 一键导出图片 / PDF 的纯前端工具。零依赖服务，双击 `index.html` 即可使用（html2canvas 与农历库均已本地化，离线可用）。

## 两种模板

| 模板 | 风格 | 适用 |
|---|---|---|
| **海报款**（默认） | 微信推文风：顶部标语、红色横幅书法大标题、可自定义配图、放假日历绶带、01/02/03 胶囊板块、底部祝福横条 | 微信群 / 朋友圈 / 公众号转发 |
| **公文款** | 红头通知风：公司落款、正文、印章、值班/备注卡片 | 正式发文、打印归档 |

## 功能

- **自定义内容**：两种模板的文案全部可编辑，实时联动预览。
- **海报款专属**：
  - 顶部标语 / 书法主标题 / 日历标题 / 底部祝福与英文标签均可自定义；
  - 配图上传（建议横图，自动裁切；不上传使用内置默认插图）；
  - 内容板块自动编号 01/02/03…，标题内容可编辑，可增删（最多 6 个）；
  - 选择节日后「放假通知」板块自动生成（如 `2026年10月1日-7日放假，共7天` + 调休上班行），手动编辑过则不再覆盖。
- **海报款日历**：周一起始，每天带农历日 / 节气（如寒露）/ 传统节日（春节、中秋、除夕等）/ 公历节日（国庆节等）标签；放假日金色圆圈、调休上班日带「班」角标，跨月自动多图并显示月份标题。
- **节日氛围自动匹配**：选择节日后自动切换整套视觉——专属配色（横幅/绶带/日历金圈/点缀色联动）、四角矢量装饰背景（春节灯笼祥云、端午龙舟粽叶、中秋圆月玉兔、国庆烟花五星、清明柳枝细雨、劳动节齿轮麦穗、元旦烟花气球）、节日专属默认插图与配套文案（标语/主标题/祝福语）。均可在「样式设置」中手动覆盖：背景样式（节日氛围/纯色/无背景）、配色主题（自动/指定节日）、是否使用节日默认插图；用户上传配图后始终优先使用上传图。
- **2026 法定节假日一键填充**：内置《国务院办公厅关于2026年部分节假日安排的通知》（国办发明电〔2025〕7号）全部 7 个节日安排；数据文件 `holidays.js` 附官方原文链接。
- **手动微调**：日历控件中点击任意日期循环切换「放假 → 调休上班 → 取消」；支持按开始/结束区间框选。
- **导出**：下载高清 PNG（2/3/4 倍可选，海报款文件名形如 `欢度国庆-放假通知.png`）；或「打印 / 存 PDF」走浏览器打印（A4 适配，自动隐藏编辑区）。
- **4 套主题**（公文款）：红金喜庆（默认）/ 商务蓝 / 清新绿 / 典雅紫；公文款含印章样式（按公司名自动取短名，可关闭）。

## 使用

**推荐：双击「启动.bat」启动**（Windows）。它会用本地服务打开页面，图片下载和打印存 PDF 直接生效；关掉黑窗口即停止服务。macOS / Linux 用 `start.sh`。

若直接双击 `index.html`（file:// 方式）打开：页面功能全部可用，但 Chrome/Edge 会静默拦截图片自动下载——点「下载图片」后会弹出预览窗，在图片上**右键 → 图片另存为**即可保存（也可点「在新标签打开」后右键保存）；「打印 / 存 PDF」不受影响。

操作步骤：

1. 启动后点击节日 chip（如「国庆节 7天」）自动填充；或手动改日期 / 在日历上点击微调。
2. 海报款：改标语/主标题、上传配图、编辑 01/02/03 板块内容。
3. 右侧预览确认后，点「下载图片」或「打印 / 存 PDF」。

## 数据准确性

- 放假调休安排：国办发明电〔2025〕7号（中国政府网原文核对）。
- 农历 / 节气：lunar-javascript 库（1900–2100），已抽样核对 2026 年国庆（10-01 国庆节、10-08 寒露、10-10 十月初一）、春节（02-16 除夕、02-17 正月初一）、中秋（09-25 八月十五）等关键日期，与官方通知口径一致。
- 公历 / 农历节日标签采用白名单过滤，只显示常见节日，避免冷门国际日干扰。

## 扩展其他年份

编辑 `holidays.js`，按现有 `festivals` 数组格式新增（`off` 放假日、`work` 调休上班日、`days` 总天数、`offText/workText` 官方口径），并调整 `app.js` 中 `syncMonthSelect` 的年份范围即可；农历无需改动。
